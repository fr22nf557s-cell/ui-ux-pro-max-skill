One-time setup

Connect this page to your GitHub

Changes you publish here are saved to the shop's repository under your own GitHub account, and the site rebuilds itself within about two minutes. You need a token that lets this page write to that one repository. It is stored only in this browser.

  1. Open github.com/settings/personal-access-tokens/new (sign in as the account that owns the shop's repository).
  2. Token name: Norvex product manager. Expiration: up to a year is fine; you can make a new one later.
  3. Repository access: Only select repositories → choose ui-ux-pro-max-skill.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else at No access.
  5. Generate the token, copy it, and paste it below.
